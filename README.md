# Canvas-Tools

Small tools for teaching with Canvas and related VU systems at Vrije Universiteit Amsterdam.

| Tool | What it does |
|---|---|
| [Syllabus to RIS](syllabus-to-ris/) | Turns a course syllabus into a RIS file for VU Reading Lists. It finds DOIs, ISBNs and full-text links, reads sections and importance levels from the syllabus, and keeps the week headings. |

Each tool has its own folder with a README.
